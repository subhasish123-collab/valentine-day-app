# Quick Deployment Commands 🚀

## Step 1: Push to GitHub

1. **Create a new repository on GitHub:**
   - Go to https://github.com/new
   - Name: `valentine-day-app`
   - Make it **Private**
   - Click "Create repository"

2. **Run these commands** (replace YOUR-USERNAME with your GitHub username):

```bash
# Navigate to project directory
cd C:\Users\SubhasishPalaur\.gemini\antigravity\scratch\valentine-app

# Add GitHub remote (REPLACE YOUR-USERNAME!)
git remote add origin https://github.com/YOUR-USERNAME/valentine-day-app.git

# Push to GitHub
git push -u origin master
```

## Step 2: Deploy to Vercel (FREE!)

1. **Go to:** https://vercel.com
2. **Sign up/Login** with GitHub
3. **Click:** "Add New Project"
4. **Import** your `valentine-day-app` repository
5. **Click:** "Deploy" (use default settings)
6. **Wait 2-3 minutes** for deployment
7. **Get your URL:** `https://valentine-day-app-xxx.vercel.app`

Your Valentine's Day website will be live and ready to share!
